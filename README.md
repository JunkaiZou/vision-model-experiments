# 多模态文本检测研究

视觉大模型（Vision Language Model）在文本检测任务中的系统性研究。通过对比提示词策略、数据增强方法和微调方案，探索 VLM 在实际文本定位任务中的性能上限。

## 项目概览

本项目是一项长期的视觉大模型文本检测能力研究，使用 **Qwen3-VL 4B** 作为基础模型，在多个标准数据集上进行了系统的实验与优化。

**核心贡献**：
- 完整的 Prompt 工程研究框架，从无先验到多种先验信息的递进式优化
- 基于 Swift 的高效微调流程，包含 LoRA、ZeRO-2、Prefix Caching 等优化
- 消融实验的系统设计与分析，揭示不同先验信息的有效性
- 工程化的推理评测加速方案

## 研究背景

### 任务定义

**文本检测**：给定图像，定位其中所有文本区域的边界框 (bounding box)。

与传统检测不同的特点：
- 文本是**高宽比不均**的对象（可能极端细长或极端宽扁）
- 文本可能**倾斜**、**竖排**或**混合排版**
- 难样本（小字、模糊、潦草）和易样本间**难度跨度大**

### 为什么用 VLM 而非 CNN？

| 维度 | CNN 检测器 | VLM 方法 |
|------|-----------|---------|
| 可解释性 | 低 | 高（可用自然语言指导） |
| 灵活性 | 固定架构 | 可通过 prompt 调整 |
| 先验利用 | 有限 | 可注入各种先验（文本内容、中心点等） |
| 微调成本 | 中等 | 低（LoRA + Adapter） |

## 核心实验组织

### 阶段 1：Prompt-Only 实验

无任何微调，仅通过精心设计的 prompt 改进性能。

**实验组**：
- **None**：无先验，纯检测提示
- **Center**：注入中心点先验
- **Random**：注入框内随机点先验
- **Text**：注入文本内容先验

**关键发现**：
- 文本先验（Text）优于坐标先验（Center/Random）
- 但坐标先验中"中心点"优于"随机点"
- 避免强制数量约束（"exactly N regions"）

### 阶段 2：SFT 实验

使用微调数据让模型学习特定的任务格式和先验类型。

**实验组**：
- **Exp1**：基线（1 epoch，LoRA, ZeRO-2）
- **Exp2**：增大上下文长度（8192 tokens）
- **Exp3**：增加训练 epoch（3 epoch）
- **Exp4**：SFT 数据的消融实验
- **Exp5**：从 4 点坐标升级到 8 点多边形
- **Exp6**：自定义 token 压缩坐标表示

**关键发现**：
- 文本列表与 GT 框的**顺序和数量对齐**很关键
- 8 点多边形格式优于 4 点矩形（特别是倾斜文本）
- 自定义 token 能节省输出长度但需要特殊优化

### 阶段 3：推理评测加速

优化推理流程，从 12 小时降至 3 小时。

**优化策略**：
- 动态 batch size 探测与缓存
- 多 worker 共享任务队列（而非静态分片）
- 并行化后处理
- 按实验组而非数据集组织推理（复用模型加载）

## 数据集

| 数据集 | 图像数 | 特点 |
|--------|--------|------|
| ICDAR2015 | ~500 | 密集小字、各种方向 |
| ICDAR2017 MLT | ~2000 | 多语言、低分辨率 |
| MSRA-TD500 | ~500 | 稀疏大字、多方向 |
| RCTW-17 | ~2500 | 真实中文、极度密集 |

## 核心指标

### Prompt-Only 最佳配置
```
数据集：ICDAR2015
配置：无先验 (None)
Precision：82.5%
Recall：76.3%
F-Measure：79.2%
```

### SFT 最佳配置
```
数据集：ICDAR2015
配置：text_cosis_8（文本先验 + 8点输出）
Precision：88.7%
Recall：85.2%
F-Measure：86.9%
```

## 可迁移的模式

此研究中建立的方法论可迁移到其他视觉任务：

1. **多先验对比框架** → 任何需要外部知识注入的检测/识别任务
2. **消融实验的系统设计** → 超参数优化的科学方法
3. **微调工程实践** → 小模型的高效适配
4. **推理加速策略** → 多卡并行推理的通用模式
